Hands-On Practice

คู่มือแบบฝึกหัดขยายฟีเจอร์แอปพลิเคชัน

ทดลองเพิ่มความสามารถจริงให้กับระบบ Smart Home Inventory ทั้งฝั่ง Go API และ Angular Signals ด้วยตัวเอง

การอ่านเรียนรู้ทฤษฎีจะมีประสิทธิภาพสูงสุดเมื่อคุณได้ลงมือ **"พิมพ์เขียนโค้ดแก้ปัญหาจริง"** ด้านล่างนี้คือ 3 โจทย์ท้าทายการพัฒนาที่จะพาคุณลงลึกไปแก้ไขขยายระบบปัจจุบันที่คุณพึ่งร่วมกันสร้างขึ้นมาครับ!

🛠️ Exercise 1 (Go API): เพิ่มระบบลบของใช้ออกจากหลังบ้าน

เป้าหมาย: พัฒนาพอร์ต REST API ฝั่งหลังบ้านด้วย Go ให้รองรับคำขอแบบ DELETE /api/items/:id เพื่อรองรับเวลาที่เราจัดของหมดแล้วอยากคัดลบสินค้าชิ้นนั้นทิ้งออกจากคลังจริง ๆ

📝 โจทย์ย่อย:

  1. สร้าง HTTP Route ใหม่ใน cmd/server/main.go ผูกกับคำขอ DELETE
  2. เขียนฟังก์ชันใน Handler item_handler.go คอยรับ Parameter ID ทาง URL พารามิเตอร์ และส่งต่อคำสั่งไปลบ

ใช้คำสั่ง c.Param("id") เพื่อแกะรหัส ID ของสินค้าออกมาจาก URL และเรียกใช้ method useCase.Delete(id) (ที่มีระบบ Lock Mutex ห้ามคนเขียนทับซ้อนซ่อนอยู่) จากนั้นส่งสถานะความสำเร็จ http.StatusOK หรือ 200 กลับไปให้หน้าบ้านรับทราบ

ขั้นตอนที่ 1.1: เขียนฟังก์ชัน Handler สแกนดักรับในไฟล์ internal/handlers/item_handler.go:

// Delete handles DELETE /api/items/:id
func (h *ItemHandler) Delete(c *gin.Context) {
	id := c.Param("id") // 👈 ดึงค่า "item_x" ออกมาจากพาร์ท URL
	
	// ส่งไปลบข้อมูลจริงใน UseCase
	// บังคับแปลง interface delete ใน Repository ให้ลบข้อมูลคีย์แม็ปทิ้ง
	err := h.useCase.Delete(id) 
	if err != nil {
		c.JSON(http.StatusInternalServerError, gin.H{"error": "Failed to delete: " + err.Error()})
		return
	}
	
	// ส่งกลับยืนยันสำเร็จ 200 OK
	c.JSON(http.StatusOK, gin.H{"message": "Item deleted successfully"})
}

ขั้นตอนที่ 1.2: ไปผูกทะเบียนเปิดเส้นทางที่ไฟล์ cmd/server/main.go:

// ค้นหากลุ่ม api.Group("/api") แล้วเพิ่มบรรทัดนี้ลงไป:
api.DELETE("/items/:id", itemHandler.Delete) // 👈 ดักฟังคำขอแบบ DELETE

🛠️ Exercise 2 (Angular Signals): ระบบปุ่มสลับกรองด่วนแสดงเฉพาะไฟแดง

เป้าหมาย: เพิ่มปุ่ม Toggle สวิตช์เปิด-ปิดด่วนบนหน้าจอเว็บ ที่เมื่อกดเปิดปุ่มแล้ว แดชบอร์ดจะกรองซ่อนของกินอื่น ๆ ทั้งหมดทิ้ง และดึงมาเฉพาะการ์ดสีส้ม/สีแดงที่ใกล้หมดสต๊อกขึ้นมาแสดงผลเท่านั้น!

📝 โจทย์ย่อย:

  1. สร้างสวิตช์ตัวเฝ้าสัญญาณใหม่ชื่อ showOnlyLowStock = signal<boolean>(false)
  2. แก้ไขสูตรคำนวณอัตโนมัติ filteredItems = computed(() => { ... }) ให้ประเมินค่าตัวสวิตช์ร่วมด้วย

ภายในวงเล็บปีกกาของ computed() ใน TypeScript เมื่อคุณเรียกใช้ this.showOnlyLowStock() ตัวแปลงสูตรจะผูกสายรับวิทยุเข้ามา หากค่านำเข้าเป็น true ให้สั่งกรองอาร์เรย์กรองเอาเฉพาะสินค้าที่ค่านั้นเข้าข่ายสต๊อกต่ำกว่า 20%

ขั้นตอนที่ 2.1: ปรับปรุงโค้ดฟิลเตอร์ที่ไฟล์ตรรกะแดชบอร์ด src/app/features/dashboard/dashboard.ts:

// 1. ประกาศตัวแปรสัญญาณ Toggle เฝ้าค่าบูลีน
showOnlyLowStock = signal<boolean>(false);

// 2. ปรับตรรกะใน computed ของ filteredItems
filteredItems = computed(() => {
  let items = this.inventoryService.items();
  const query = this.searchQuery().toLowerCase().trim();
  const category = this.selectedCategory();
  const onlyLow = this.showOnlyLowStock(); // 👈 ดึงค่าวิทยุตลอดเวลา

  // กรองตามคำค้นหา
  if (query) {
    items = items.filter((item) => item.name.toLowerCase().includes(query));
  }

  // กรองตามหมวดหมู่
  if (category) {
    items = items.filter((item) => item.category === category);
  }

  // ⭐️ กรองตามสวิตช์ไฟแดงเตือน
  if (onlyLow) {
    items = items.filter((item) => (item.currentStock / item.baseQuantity) <= 0.20);
  }

  return items;
});

// ฟังก์ชันสำหรับสั่งเปิดปิดสวิตช์สลับไปมา
toggleLowStockFilter() {
  this.showOnlyLowStock.set(!this.showOnlyLowStock()); // 👈 สลับค่า true <-> false
}

ขั้นตอนที่ 2.2: แปะปุ่มกดสวิตช์สวย ๆ เรืองแสงลงบน HTML src/app/features/dashboard/dashboard.html:

<!-- เพิ่มลงไปถัดจากปุ่มเพิ่มสินค้า หรือบริเวณกล่องค้นหาข้อมูล -->

🛠️ Exercise 3 (Full-Stack): ปุ่มคลิกลบการ์ดของใช้ออกหน้าเว็บทันที

เป้าหมาย: การต่อท่อเชื่อมแบบ full-stack! เพิ่มปุ่มไอคอนถังขยะสีแดงลงบนการ์ดสินค้าทุกใบในแดชบอร์ด เมื่อคลิกจะยิง AJAX DELETE ไปหลังบ้าน Go เพื่อเคลียร์ฐานข้อมูลจำลอง จากนั้น Signal Store จะทำการคัดชื่อตัวแปร ID นั้นทิ้ง เพื่อลบการ์ดออกจากจอในบัดดล!

📝 โจทย์ย่อย:

  1. เพิ่มพอร์ตเรียกใช้ลบข้อมูลใน core/http/api.ts
  2. สร้างแอคชันรับฟันฟลักซ์ใน Signal core/services/inventory.service.ts
  3. เพิ่มปุ่มกดลงบน HTML การ์ดทุกใบ

ขั้นตอนที่ 3.1: เขียนตัวยิง DELETE ในฝั่ง Client `src/app/core/http/api.ts`:

// ยิงคำขอลบสินค้า
deleteItem(id: string): Observable<any> {
  return this.http.delete(`${this.baseUrl}/items/${id}`);
}

ขั้นตอนที่ 3.2: เพิ่มแอคชันทำลายข้อมูลใน Signal Store `src/app/core/services/inventory.service.ts`:

// Action สำหรับลบสินค้าและนำออกจากการจำลอง State
removeItem(id: string) {
  this.api.deleteItem(id).subscribe({
    next: () => {
      // ดึงอาร์เรย์เดิมและกรองลบคัดตัวที่มี ID ตรงทิ้งไป
      const updated = this._items().filter(item => item.id !== id);
      this._items.set(updated); // 👈 อัปเดต Signal ทันที!
    },
    error: (err) => {
      console.error("ลบข้อมูลไม่สำเร็จ", err);
      this._error.set("ไม่สามารถลบสินค้าชิ้นนี้ได้");
    }
  });
}

ขั้นตอนที่ 3.3: สร้างฟังก์ชันคำสั่งดักคลิกปุ่มบนคอนโทรลเลอร์ `src/app/features/dashboard/dashboard.ts`:

// ฟังก์ชันคลิกลบสินค้า
deleteItem(id: string) {
  if (confirm("คุณแน่ใจหรือไม่ที่จะลบของใช้ชิ้นนี้ออกจากคลังบ้าน?")) {
    this.inventoryService.removeItem(id);
  }
}
