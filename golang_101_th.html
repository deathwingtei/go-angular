Go Lang 101 Reference

Go Lang 101: คู่มือปูพื้นฐานฉบับผู้เริ่มต้นจากศูนย์

เรียนรู้หลักไวยากรณ์ การประกาศตัวแปร โครงสร้างข้อมูล และระบบการรันขนานกันของภาษา Go

📌 1. ปรัชญาของภาษา Go: ทำไมคนถึงนิยมใช้?

ภาษา Go ถูกสร้างขึ้นโดยทีมวิศวกรของ Google (รวมถึงคุณ Rob Pike และ Ken Thompson ผู้สร้างระบบปฏิบัติการ Unix) โดยมุ่งเน้นปรัชญาสำคัญคือ "ความง่าย สั้นกระชับ และเสถียรสุดยอด" Go แตกต่างจากภาษาทั่วไปคือ:

  • มีคีย์เวิร์ดควบคุมการทำงานเพียง 25 คำ: ทำให้เขียนโค้ดได้กระชับ เรียนรู้ง่ายมาก เรียนแค่วันเดียวก็เขียนได้!
  • แปลงเป็นไฟล์รันตรงไม่ต้องใช้โปรแกรมครอบ (Compiled Language): Go แปลงซอร์สโค้ดของคุณตรงเข้าสู่ Machine Code (ไฟล์ .exe หรือไบนารี) ทำให้มันเปิดตัวได้เร็วเฉียบเสี้ยววินาทีและกินแรมน้อยมาก

📌 2. การประกาศตัวแปรและการจัดการประเภทข้อมูล

ในภาษา Go เราต้องประกาศชนิดข้อมูล (Type) ให้ตัวแปรอย่างชัดเจน มี 2 วิธีหลักในการประกาศตัวแปร:

วิธีที่ 1: ใช้คีย์เวิร์ดมาตรฐาน var (กำหนดค่าเริ่มต้นได้)

var name string = "น้ำยาซักผ้า"
var currentStock float64 = 4.5
var isActive bool = true

วิธีที่ 2: ใช้เครื่องหมายลัดสุดฮิต := (Short Variable Declaration)

วิธีนี้ใช้สัญลักษณ์ := ในการจับคู่ข้อมูล โดยตัวภาษา Go จะแอบมองค่าขวาแล้ววิเคราะห์แอบเลือก Type ให้เราเองอัตโนมัติ (เขียนได้เฉพาะในฟังก์ชันเท่านั้น): 

name := "นมสดพาสเจอร์ไรส์" // Go จะประเมินว่าเป็นประเภท string
currentStock := 10.0      // Go จะประเมินว่าเป็นประเภท float64
isActive := false         // Go จะประเมินว่าเป็นประเภท bool

📌 3. การควบคุมทิศทางโปรแกรม (If-Else & For Loops)

1. การเปรียบเทียบตรรกะแบบไม่ต้องมีวงเล็บ (If-Else)

ภาษา Go สั่งห้ามใส่วงเล็บรอบการตรวจจับตัวแปร ซึ่งทำให้โค้ดมีความคลีนสะอาดตามาก: 

if currentStock <= 0 {
    fmt.Println("วิกฤต! ของหมดแล้ว")
} else if currentStock / baseQuantity <= 0.2 {
    fmt.Println("คำเตือน: ของใกล้หมดคลัง")
} else {
    fmt.Println("ปกติ: ปริมาณยังพอใช้")
}

2. การทำซ้ำแบบไม่มีวันสิ้นสุด (For Loop)

Go เป็นภาษาที่ฉลาดมากและเลือกตัดคำสั่งยุ่งเหยิงออก ในภาษา Go จะไม่มีคำสั่ง loop ชนิด while หรือ do-while แต่ใช้เพียงคำสั่ง for แบบเดียวเพื่อแทนทุกอย่าง! 

// 1. Loop ทั่วไปแบบนับจำนวน (Loop แบบดั้งเดิม)
for i := 0; i < 5; i++ {
    fmt.Println("รอบที่:", i)
}

// 2. Loop คอยตรวจจับสถานะ (ทำหน้าที่เหมือน while loop ในภาษาอื่น)
for isActive {
    // ทำงานไปเรื่อย ๆ ตราบใดที่ isActive ยังคงเป็น true
}

// 3. Loop ทะลวงกลุ่มข้อมูล (Range Loop ดึงดัชนีและค่าออกมาใช้งาน)
items := []string{"นม", "สบู่", "ข้าวสาร"}
for index, item := range items {
    fmt.Printf("ตำแหน่งที่ %d คือของสิ่งนี้: %s\n", index, item)
}

📌 4. โครงสร้างข้อมูลขั้นสูง: Struct & Method

เมื่อต้องการเอาตัวแปรหลาย ๆ ชิ้นมารวมร่างกันเพื่อจัดระเบียบข้อมูลเป็นกล่อง ๆ เราจะใช้ struct และหากต้องการเขียนฟังก์ชันให้ไปติดอยู่บนตัว Struct นั้น (เหมือนคลาสใน OOP) เราจะเรียกว่า Method: 

package main

import "fmt"

// 1. ประกาศโครงสร้าง Struct แปะป้ายคุณสมบัติ
type Bottle struct {
	Name         string
	CurrentVolume float64
}

// 2. เขียน Method ผูกติดก้นขวด (การรับค่าแบบ pointer)
// สังเกตตัวแปรผูกหน้า (b *Bottle) เรียกว่า Receiver
func (b *Bottle) Use(amount float64) {
	b.CurrentVolume -= amount
	if b.CurrentVolume < 0 {
		b.CurrentVolume = 0
	}
	fmt.Printf("ใช้ %s ไปปริมาณ %.1f\n", b.Name, amount)
}

func main() {
	myMilk := Bottle{Name: "นมพาสเจอร์ไรส์ Meiji", CurrentVolume: 1000}
	
	// เรียกใช้ Method บน struct
	myMilk.Use(250)
	
	fmt.Printf("ปริมาณนมคงเหลือ: %.1f ml\n", myMilk.CurrentVolume) // ได้ผลลัพธ์ 750.0
}

📌 5. ปลดล็อคความกลัว: Pointer คืออะไร? (พอยน์เตอร์แบบเข้าใจง่ายสุด ๆ)

หลายคนกลัวคำว่า Pointer (พอยน์เตอร์) แต่ใน Go มันง่ายมาก! ลองนึกภาพ: ตัวแปรปกติเหมือน "กระดาษถ่ายเอกสาร" และ Pointer เหมือน "ป้ายชี้ตำแหน่งพิกัดบ้าน":

เปรียบเทียบในชีวิตจริง:
สมมติว่าคุณมีบ้านเลขที่หนึ่งตัว (ค่าตัวแปรในหน่วยความจำ RAM)
- หากส่งตัวแปรปกติไปที่อื่น: เหมือนคุณถ่ายเอกสารรูปภาพบ้านไปให้คนอื่นวาดต่อ เขาระบายสีเล่นบนกระดาษใบนั้น บ้านจริง ๆ ของคุณจะไม่เปลี่ยนสี!
- หากใช้ Pointer (ส่งบ้านเลขที่ชี้ทางไป): เหมือนคุณยื่นแผนที่ให้เขาเดินมาที่หน้าบ้านจริง ๆ ของคุณแล้วลุยพ่นสเปรย์ระบายสีบ้านคุณ เมื่อเขากลับไป บ้านจริง ๆ ของคุณจะเปลี่ยนสีไปถาวร!

ไวยากรณ์สัญลักษณ์หลักใน Go มีเพียง 2 ตัว:

  • เครื่องหมาย & (แอมเพอร์แซนด์): ย่อมาจาก "หาพิกัดบ้านเลขที่ของตัวแปรนี้มาซิ" (Address-of operator)
  • เครื่องหมาย * (แอสเทอริสค์): ย่อมาจาก "เดินตามพิกัดแผนที่ไปทะลวงเปิดห้องกล่องข้อมูลข้างใน" (Dereference operator)
func main() {
    milkStock := 10.0 // ตัวแปรเก็บจำนวนนมสด
    
    // 1. หาแผนที่บ้านของตัวแปรนี้โดยใส่ & ด้านหน้า
    pointerToStock := &milkStock 
    
    fmt.Println(pointerToStock)  // พ่นที่อยู่บ้านเลขที่ในแร็มออกมา เช่น 0xc0000120b8
    
    // 2. ถ้าใส่ * ข้างหน้า ตัวชี้ทางจะไปเปลี่ยนค่าที่อยู่ของบ้านหลังจริงถาวร!
    *pointerToStock = 5.0 
    
    fmt.Println(milkStock) // ได้ผลลัพธ์ 5.0 (เปลี่ยนค่าตัวแปรจริงถาวร!)
}

📌 6. ระบบวิ่งขนานของ Go: Goroutine & sync.RWMutex

เมื่อรันเว็บเซิร์ฟเวอร์ ภาษา Go จะรันคิวประมวลผลของผู้ใช้งานขนานกันด้วยสิ่งเล็ก ๆ ที่เรียกว่า Goroutine ซึ่งเป็นเทรดขนาดเล็กมากที่กินทรัพยากรน้อยกว่าเทรดทั่วไปถึง 1,000 เท่า!

และเมื่อเรามีการเขียนอ่านข้อมูลขนานกัน เพื่อป้องกันความโกลาหล เราใช้ sync.RWMutex ในการควบคุม: 

type SafeInventory struct {
    mu   sync.RWMutex // 👈 ค้ำควบคุมความปลอดภัย
    data map[string]float64
}

// ทุกครั้งที่จะบันทึกแก้ไขสต๊อก ให้เปิดใช้ Lock สิทธิ์ขาดคนเดียว!
func (s *SafeInventory) Write(key string, val float64) {
    s.mu.Lock()
    defer s.mu.Unlock() // ปลดล็อคกุญแจทันทีเมื่อแก้ไขสต๊อกเสร็จสิ้น
    s.data[key] = val
}
