คู่มือเรียนรู้และสร้างแอปพลิเคชันจากศูนย์

เขียนโค้ดและทำความเข้าใจ Go Backend (REST API) & Angular (Signals) สำหรับผู้เริ่มต้นที่ไม่มีพื้นฐานเลย

🧩 1. ความเข้าใจเบื้องต้น: สองภาษาทำงานร่วมกันอย่างไร?

หากคุณไม่เคยเขียนโปรแกรมมาก่อน ลองจินตนาการระบบนี้เหมือน "ร้านขายอาหารตามสั่ง":

  • Go Backend (หลังบ้าน): ทำหน้าที่เหมือน "พ่อครัวในห้องครัว" คอยจัดแจงของใช้ ทำนายคำนวณสูตรว่านมกล่องนี้จะหมดในอีกกี่วันตามสถิติเก็บข้อมูล พ่อครัวจะไม่คุยกับลูกค้าโดยตรง แต่จะคอยทำอาหาร (เตรียมข้อมูล JSON) วางไว้ที่หน้าตู้ส่งของ (API Endpoint)
  • Angular Frontend (หน้าบ้าน): ทำหน้าที่เหมือน "พนักงานเสิร์ฟผู้น่ารัก" คอยเดินไปต้อนรับลูกค้า ยื่นสมุดเมนูสวย ๆ ให้เลือก (หน้าแดชบอร์ด) คอยรับคำสั่งลูกค้าแล้วเดินเอาออเดอร์นั้น (HTTP Request) ไปบอกพ่อครัวในห้องครัว เมื่อได้รับของก็รีบนำมาจัดวางบนโต๊ะให้ลูกค้าอย่างลื่นไหลและมีสไตล์

เปรียบเทียบในชีวิตจริง:
เวลาคุณเปิดเว็บ จอภาพและการ์ดใส ๆ ที่คุณคลิกกดตัดสต๊อกนั่นคือฝั่ง Angular แต่ตัวแปรปริมาณสต๊อกที่เปลี่ยนไปและการคำนวณวันทำนายจะถูกส่งผ่านสายเคเบิลอินเทอร์เน็ตไปคิดเลขใน Go แล้วสะท้อนข้อมูลกลับมาแสดงผลทันที!

🐹 2. เจาะลึกฝั่ง Go Backend (สำหรับผู้เริ่มต้น)

ภาษา Go เป็นภาษาที่เด่นในเรื่องความรวดเร็วและกินแรมน้อยมาก เหมาะมากที่จะนำมาทำตัวประมวลผลข้อมูล

🛠️ สิ่งที่ต้องรู้จัก 1: Struct (กล่องจัดระเบียบของใช้)

ในภาษา Go เมื่อต้องการประกาศ "กลุ่มข้อมูล" เราจะใช้คีย์เวิร์ด struct (อ่านว่า สะ-ตรัค-ต) เปรียบเสมือน "กล่องใบใหญ่ที่แปะป้ายระบุข้างกล่องว่าข้างในเก็บอะไรบ้าง" เช่น แปะป้ายบอกชื่อ ปริมาณ และหน่วยนับ

ลองมาดูการสร้างไฟล์โมดูลข้อมูลชิ้นแรกในโฟลเดอร์โครงการที่ไฟล์ internal/models/item.go:

package models

import "time" // นำเข้าไลบรารีเวลา

// InventoryItem คือกล่องระบุว่าของใช้ในบ้านมีคุณสมบัติอะไรบ้าง
type InventoryItem struct {
	ID                string    `json:"id"`                // ชื่อ ID สลักติดสินค้า
	Name              string    `json:"name"`              // ชื่อของชิ้นนั้น (เช่น "นมสด")
	Category          string    `json:"category"`          // หมวดหมู่ (เช่น "ห้องครัว")
	CurrentStock      float64   `json:"currentStock"`      // จำนวนที่มีในสต๊อกตอนนี้
	BaseQuantity      float64   `json:"baseQuantity"`      // จำนวนเต็มตอนเติมเต็มขวด
	Unit              string    `json:"unit"`              // หน่วยนับ เช่น "ขวด", "ml"
	LastRestockDate   time.Time `json:"lastRestockDate"`   // วันที่บันทึกเติมล่าสุด
	ReplenishmentDate time.Time `json:"replenishmentDate"`  // วันคาดการณ์สินค้าหมดคลัง
}

สัญลักษณ์แปลก ๆ ด้านหลังฟิลด์คืออะไร? (Struct Tags):
สัญลักษณ์ `json:"currentStock"` คือการเขียนป้ายบอกตัวภาษา Go ว่า: "เวลาเธอแปลงกล่องนี้ให้กลายเป็น JSON เพื่อส่งผ่านเน็ตไปให้ Angular ช่วยกรุณาเปลี่ยนคำว่า CurrentStock (ภาษา Go นิยมขึ้นต้นพิมพ์ใหญ่) เป็นคำว่า currentStock (คีย์พิมพ์เล็กสไตล์ JavaScript) ด้วยนะ"

🛠️ สิ่งที่ต้องรู้จัก 2: Concurrency & RWMutex (กุญแจห้องน้ำสำหรับ Goroutine)

เมื่อเราเปิดรัน REST API ขึ้นมา เซิร์ฟเวอร์ Go จะรองรับคนเรียกเข้าใช้งานหลายคนพร้อมกันในเวลาเสี้ยววินาที ภาษา Go จะสร้างเส้นด้ายการทำงานขนานกันที่เรียกว่า Goroutine มาคอยประมวลผลคำขอ

ลองนึกภาพ: ถ้าคนในบ้าน 2 คนกดปุ่ม "ลดสต๊อก" ในเสี้ยววินาทีเดียวกัน หากไม่มีเครื่องมือห้ามคิว โค้ดของเราจะอ่านข้อมูลพร้อมกัน ข้อมูลจะเพี้ยนหรือพังทันที! เราแก้ปัญหานี้โดยใช้ sync.RWMutex เปรียบเสมือน "กุญแจห้องน้ำ":

  • สิทธิ์การอ่าน (RLock): เหมือนห้องน้ำที่มีกระจกส่องหน้าบานใหญ่ คนสามารถยืนอ่านดูสต๊อก (มองส่องกระจก) พร้อมกันได้หลายคนโดยไม่อันตราย
  • สิทธิ์การเขียน (Lock): เหมือนการเข้าห้องน้ำแบบทำธุระส่วนตัว ทันทีที่มีคนจะเปลี่ยนสต๊อก (เข้าห้องน้ำไปเปลี่ยนกางเกง) จะต้องล็อคสิทธิ์ไว้ ห้ามใครเข้ามาอ่านหรือเขียนเด็ดขาดจนกว่าจะเสร็จธุระ!

ดูโค้ดจัดการ Database จำลองที่ไฟล์ internal/repository/inmemory.go:

package repository

import (
	"errors"
	"my-go-app/internal/models"
	"sync" // 👈 เรียกใช้ sync เพื่อเอา Mutex มาไขกุญแจ
)

type InMemoryItemRepository struct {
	mu    sync.RWMutex // 👈 กุญแจควบคุมคนอ่าน/เขียน
	items map[string]models.InventoryItem
}

// อ่านสินค้า (คนเข้าอ่านพร้อมกันได้)
func (r *InMemoryItemRepository) GetAll() ([]models.InventoryItem, error) {
	r.mu.RLock()         // 👈 ล็อคเพื่ออ่าน (ใครจะเขียนรอก่อน ใครจะอ่านด้วยกันเชิญเลย!)
	defer r.mu.RUnlock() // 👈 ปลดล็อคอัตโนมัติเมื่อทำฟังก์ชันเสร็จสิ้น

	items := make([]models.InventoryItem, 0, len(r.items))
	for _, item := range r.items {
		items = append(items, item)
	}
	return items, nil
}

// แก้ไขสต๊อกสินค้า (ห้ามอ่านห้ามเปลี่ยนแปลงทับซ้อน)
func (r *InMemoryItemRepository) Update(item models.InventoryItem) (models.InventoryItem, error) {
	r.mu.Lock()         // 👈 ล็อคสิทธิ์ขาด (ห้ามใครแตะต้องเลย ฉันจะเปลี่ยนค่าแปร!)
	defer r.mu.Unlock() // 👈 ปลดล็อคเมื่อเขียนเสร็จ

	if _, exists := r.items[item.ID]; !exists {
		return models.InventoryItem{}, errors.New("item not found")
	}
	r.items[item.ID] = item
	return item, nil
}

📐 3. เจาะลึกฝั่ง Angular Frontend (สำหรับผู้เริ่มต้น)

Angular เป็นเฟรมเวิร์กสร้างหน้าเว็บที่ออกแบบมาเพื่อให้หน้าจอมีความเสถียรและทนทานมาก

🛠️ สิ่งที่ต้องรู้จัก 1: Standalone Component & Route (การจัดพาร์ทและหน้าจอเดี่ยว)

ใน Angular รุ่นเก่า การจะสร้างปุ่มหรือหน้าเว็บสักหน้า คุณต้องสร้างไฟล์และนำมาประกาศลงทะเบียนในสิ่งที่เรียกว่า `NgModule` วุ่นวายและซับซ้อนมาก แต่ใน Angular 17+ เรามีระบบ Standalone Component:

เปรียบเทียบในชีวิตจริง:
คอมโพเนนต์เดี่ยว (Standalone) เหมือน "เครื่องใช้ไฟฟ้ากล่องสำร็จรูปสำเร็จรูป" ที่มีหัวปลั๊กไฟในตัว (Imports) คุณสามารถซื้อทีวี (Component) เสียบปลั๊กเปิดเล่นได้ทันที โดยไม่ต้องผ่านศูนย์ควบคุมบอร์ดไฟกลางของบ้านอีกต่อไป!

วิธีกำหนดหน้าพาร์ทเร้าติ้งของเว็บที่ไฟล์ src/app/app.routes.ts:

import { Routes } from '@angular/router';
import { Dashboard } from './features/dashboard/dashboard';

export const routes: Routes = [
  {
    path: '',              // 👈 หากผู้ใช้เปิดหน้าเว็บมาว่าง ๆ (เช่น http://localhost:4200)
    component: Dashboard,  // 👈 สั่งให้แสดงผลหน้าจอ Dashboard ขึ้นมาทันที
  }

🛠️ สิ่งที่ต้องรู้จัก 2: Signals & computed (โคมไฟอัจฉริยะกะพริบแจ้งเตือนคอยเฝ้าสถิติ)

นี่คือนวัตกรรมที่ดีที่สุดของหน้าบ้าน! ในหน้าจอระบบเดิม ๆ เวลาคุณเปลี่ยนสต๊อก คุณต้องสั่งให้เว็บหน้าจอทำการรีเฟรชรีเซ็ตโหลดตัวเว็บใหม่ (F5) ซึ่งช้ามาก ระบบยุคใหม่จึงแก้ด้วยการทำ **Reactive State** และใช้ **Signals**:

  • Signal (ตัวส่งสัญญาณ - `signal`): เหมือน "โคมไฟสีเปลี่ยนสีได้" เมื่อปริมาณของลดลง โคมไฟดวงนี้จะส่งคลื่นวิทยุออกไปบอกคนรอบ ๆ ว่า "ฉันเหลือสต๊อก 2 ขวดแล้วนะ!"
  • Computed (ตัวแปลงผลสัญญาณอัตโนมัติ - `computed`): เหมือน "ป้ายอัจฉริยะไฟสัญญาณเตือนวิกฤต" ที่ไม่เก็บข้อมูลเดี่ยว แต่จะผูกสายสัญญาณเชื่อมไว้กับโคมไฟสต๊อก เมื่อใดก็ตามที่วิทยุของโคมไฟขยับเปลี่ยนตัวเลข ป้ายเตือนนี้จะคำนวณสูตรคณิตศาสตร์ทันทีโดยอัตโนมัติ ไม่ต้องสั่งรีโหลดหน้าจอใหม่!

ดูโค้ดสร้างกล่องจัดระเบียบสัญญาณในไฟล์ src/app/core/services/inventory.service.ts:

import { Injectable, signal, computed } from '@angular/core';
import { InventoryItem } from '../models/inventory-item';

@Injectable({
  providedIn: 'root',
})
export class InventoryService {
  // 1. สร้างสัญญาณดิบเก็บลิสต์สินค้า (เหมือนโคมไฟส่องสว่างส่งวิทยุได้)
  private _items = signal<InventoryItem[]>([]);
  items = this._items.asReadonly(); // ให้คนนอกดึงอ่านได้อย่างเดียว ป้องกันการแก้ไขนอกระบบ

  // 2. ⭐️ computed มหัศจรรย์: คอยดักฟัง _items() เปลี่ยนแปลง เพื่อทำสูตรเลขทันที
  totalItems = computed(() => this._items().length); // หาจำนวนชิ้นรวมในบ้าน

  // คอยกรองรายการสินค้าที่จัดเป็นระดับวิกฤตสต๊อกต่ำกว่า 20% อัตโนมัติ
  lowStockItems = computed(() =>
    this._items().filter((item) => item.currentStock / item.baseQuantity <= 0.20)
  );

  lowStockCount = computed(() => this.lowStockItems().length); // คำนวณจำนวนชิ้นที่ไฟแดงเตือน
}

🚨 ประโยชน์มหึมาของ Signals

ด้วย Signals และ computed ทำให้เวลาคุณกดลดสต๊อกนมสด แถบวงกลมแสดงความคืบหน้า HSL และจำนวนสรุปไฟแดงวิกฤตด้านบนแดชบอร์ดจะกระพริบอัปเดตสีและจำนวนใหม่ทันทีภายใน 0.001 วินาที โดยไม่ต้องรีเฟรชหน้าเว็บทั้งแผ่น!

🚀 4. คู่มือรันคำสั่งและการรันเซิร์ฟเวอร์ครั้งแรกสำหรับมือใหม่

หลังจากที่คุณพิมพ์โค้ดเสร็จเรียบร้อย การเชื่อมโยงให้ทั้ง 2 ฝั่งทำงานร่วมกันทำได้ง่าย ๆ ดังนี้:

📌 ขั้นตอนฝั่ง Go Backend (พอร์ต :8080)

  1. เปิดโปรแกรม Terminal หรือ Command Prompt ขึ้นมาแล้วพิมพ์คำสั่งย้ายโฟลเดอร์เข้าไปในไดเรกทอรีโครงการฝั่ง API
  2. พิมพ์คำสั่งเพื่อดาวน์โหลดโมดูลและรันโครงการ: 
    go run cmd/server/main.go
  3. คุณจะเห็นข้อความ [GIN-debug] Listening and serving HTTP on :8080 ปรากฏขึ้น เป็นสัญญาณว่าด่านหลังบ้านพร้อมทำหน้าที่ปรุงออเดอร์แล้ว!

📌 ขั้นตอนฝั่ง Angular Frontend (พอร์ต :4200)

  1. เปิดโปรแกรม Terminal แยกขึ้นมาอีกหน้าต่างหนึ่ง แล้วขยับโฟลเดอร์เข้าไปที่ web/ ของหน้าบ้าน
  2. พิมพ์คำสั่งรันระบบเซิร์ฟเวอร์พัฒนาผ่านคำสั่งพิมพ์เพื่อรัน: 
    npm start
  3. หากมีข้อผิดพลาดระบบการเปิดใช้ PowerShell ของเครื่อง Windows ให้พิมพ์คำสั่งหลบหลีกแทนดังนี้: 
    cmd /c npm start
  4. เมื่อการบิวด์เสร็จสมบูรณ์ จะปรากฏข้อความระบุ ➜ Local: http://localhost:4200/
  5. ให้ใช้เมาส์คลิกเปิดลิงก์เบราว์เซอร์ไปที่ [http://localhost:4200/](http://localhost:4200/) คุณจะเข้าสัมผัสความสวยงามและใช้งานระบบทำนายของใช้อัจฉริยะได้ทันที!
