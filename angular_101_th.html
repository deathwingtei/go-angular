Angular 101 Reference

Angular 101: คู่มือปูพื้นฐานฉบับผู้เริ่มต้นจากศูนย์

เรียนรู้วงจรคอมโพเนนต์เดี่ยว การตั้งค่าเส้นทางเว็บ การผูกข้อมูล และสเตทเทคโนโลยี Signals

📌 1. ปรัชญาและโครงสร้างคอมโพเนนต์ (Component Anatomy)

Angular ยุคใหม่ (v15+) ขยายความสามารถให้ตัวเว็บประกอบขึ้นมาจากสิ่งเล็ก ๆ ที่เรียกว่า Component (คอมโพเนนต์) ซึ่งเป็นชิ้นส่วนบล็อกอิสระที่ภายในประกอบด้วย 3 ส่วนสำคัญทำหน้าที่ร่วมกัน:

  1. ไฟล์ตรรกะประมวลผล (TypeScript - `.ts`): ทำหน้าที่กำหนดสมองของคอมโพเนนต์ คอยคิดเลข ยิง API และสร้างสเตทข้อมูลตัวแปร
  2. ไฟล์หน้าจอโครงสร้าง (HTML Template - `.html`): จัดวางเลย์เอาต์ ป้ายข้อความ ช่องกรอกฟอร์ม และปุ่มต่าง ๆ
  3. ไฟล์ตกแต่งสีสัน (CSS Styles - `.css`): ตกแต่งความสวยงามเฉพาะตัวของการ์ดชิ้นนั้น ๆ โดยไม่ก้าวก่ายรบกวนคอมโพเนนต์อื่น

ตัวอย่างการประกาศโครงสร้างโค้ด TypeScript บนคอมโพเนนต์เดี่ยว (Standalone Component):

import { Component } from '@angular/core';

@Component({
  selector: 'app-hello-tag',     // 👈 ชื่อแท็กส่วนตัวเอาไว้เรียกใช้บน HTML (เช่น <app-hello-tag>)
  standalone: true,              // 👈 ประกาศเป็นคอมโพเนนต์เดี่ยว สำเร็จรูปพร้อมรัน
  template: `
    <div class="hello-box">
      <h3>สวัสดี: {{ userName }}</h3>
    </div>
  `,
  styles: `
    .hello-box { padding: 10px; border: 1px solid purple; }
  `
})
export class HelloTag {
  userName = 'นักเรียนรู้หน้าบ้าน';
}

📌 2. การเชื่อมโยงข้อมูล 4 มิติ (Data Bindings)

นี่คือหัวใจการทำหน้าที่ของพนักงานเสิร์ฟ! เป็นการรับส่งข้อมูลระหว่างตัวแปรใน TypeScript กับแท็กปุ่มบนหน้าจอ HTML มี 4 วิธีดังนี้:

1. แสดงค่าตัวแปรออกหน้าจอ (Text Interpolation - {{ }})

เป็นการดึงค่าในตัวแปรฝั่ง TypeScript มาพ่นพิมพ์ใส่เป็นป้ายข้อความบน HTML ด้วยเครื่องหมายปีกกาคู่:

<!-- ดึงตัวแปร message มาพิมพ์แสดง -->
<p>ข้อความแจ้งเตือน: {{ message }}</p>

2. การส่งข้อมูลเข้าคุมแท็ก (Property Binding - [property]="value")

เป็นการเอาค่าตัวแปรฝั่ง TypeScript ไปควบคุมคุณสมบัติ (Attribute) ของแท็ก HTML เช่น สั่งปิดปุ่ม หรือเปลี่ยนพิกัดภาพ:

<!-- สั่งปิดปุ่มใช้งานตามค่าตัวแปร isLoading (ถ้าเป็น true ปุ่มจะกดไม่ได้) -->
<button [disabled]="isLoading">ส่งข้อมูล</button>

3. การดักรับการกดและพิมพ์ของผู้ใช้ (Event Binding - (event)="method()")

เมื่อลูกค้าคลิกหน้าจอหรือพิมพ์คีย์บอร์ด จะวิ่งไปสั่งฟังก์ชันใน TypeScript ให้ทำงาน:

<!-- เมื่อลูกค้าคลิกเมาส์ สั่งให้ฟังก์ชัน cutStock() ทำงานทันที -->
<button (click)="cutStock()">📉 ตัดสต๊อก</button>

4. การรับส่งข้อมูลสองทางสไตล์กรอกฟอร์ม (Two-Way Binding - [(ngModel)]="value")

ใช้กับฟอร์มกรอกตัวเลข/ตัวอักษร เมื่อคุณพิมพ์ในช่อง ข้อมูลตัวแปรในสมองจะอัปเดต และหากตัวแปรเปลี่ยน ตัวเลขในช่องจะวิ่งเปลี่ยนตามด้วยอัตโนมัติ:

<!-- ผูกโยงตัวแปร itemName เข้ามาที่ช่องกรอกตัวอักษรแบบเรียลไทม์ -->
<input [(ngModel)]="itemName" placeholder="กรอกของใช้..." />

📌 3. การควบคุมโครงสร้างแสดงผลตัวใหม่ (Modern Control Flow)

Angular 17 ได้รับการปรับปรุงครั้งใหญ่ที่สุด โดยการยกเครื่องเงื่อนไข `@if` และการทำซ้ำ `@for` ให้มีความไวระดับเทพและจำง่ายมากสำหรับมือใหม่:

1. การสลับวิวหน้าจอตามเงื่อนไข (@if / @else)

@if (loading()) {
  <p>🌀 กำลังโหลดข้อมูล...</p>
} @else {
  <p>✅ โหลดรายการของใช้เสร็จเรียบร้อย!</p>
}

2. การวนซ้ำลิสต์สินค้าออกมาโชว์ (@for)

การทำซ้ำด้วย @for ใน Angular บังคับให้ใส่คำสั่ง track เสมอ เพื่อคอยมองคีย์ระบุตัวตนของการ์ด ทำให้บราวเซอร์รู้เฉพาะจุดที่มีการลดสต๊อกและเปลี่ยนสีการ์ดใบเดียว ไม่โหลดพังการ์ดใบอื่นรอบ ๆ: 

<ul>
  @for (item of items(); track item.id) {
    <li>{{ item.name }} - จำนวนคงเหลือ {{ item.currentStock }} {{ item.unit }}</li>
  } @empty {
    <p>📂 ไม่มีของใช้ชิ้นใดอยู่ในบ้านของคุณเลย</p>
  }
</ul>

📌 4. เจาะลึกความมหัศจรรย์ของ Angular Signals

เมื่อก่อนเราใช้ RxJS ในการอัปเดตสเตทข้อมูล ซึ่งมีไวยากรณ์เข้าใจยาก ซับซ้อน และลัดหาบั๊กยากมาก Angular จึงแก้ปัญหาโดยปล่อยเครื่องมือ **Signals** ออกมา:

Signals คืออะไร?
เปรียบเหมือนตัวแปรทั่วไป แต่มีระบบ "สายไฟวิทยุคอยแผ่สัญญาณเสียงก้องรอบห้อง" ทุกครั้งที่คุณเปิดฟังหรือปรับเปลี่ยนค่า คลื่นจะไปอัปเดตวิวของหน้าเว็บจุดที่แปะป้ายไว้อัตโนมัติทันที

1. การประกาศโคมไฟคอยเฝ้าสัญญาณเดี๋ยว (signal)

// สร้างตัวเฝ้าสัญญาณเก็บตัวเลขสต๊อกปัจจุบัน เริ่มต้นด้วยค่า 10
stock = signal<number>(10);

// วิธีดึงตัวเลขในสัญญาณออกมาใช้งาน (ต้องใส่วงเล็บต่อท้ายตัวแปรเสมอ!)
console.log(this.stock()); // ได้ผลลัพธ์ 10

// วิธีการอัปเดตเปลี่ยนค่าสต๊อกในสัญญาณ
this.stock.set(5); // สั่งสวิทช์เป็นค่า 5 หน้าจอที่มีตัวแปรนี้จะเปลี่ยนเลขตามทันที!

2. ⭐️ ตัวทรานสฟอร์เมอร์สูตรอัตโนมัติ (computed)

เป็นสัญญาณระดับรองที่ไม่มีคิวเก็บข้อมูลเดี่ยวเป็นของตัวเอง แต่จะแอบเอาคีย์สัญญาณดิบตัวหลักมาคอยประเมินคำนวณสูตรเลขตลอดเวลา: 

// ดักวิทยุของตัวแปร stock ตลอดเวลาเพื่อคำนวณเป็นร้อยละ
percent = computed(() => {
  const current = this.stock();
  const maxCapacity = 20;
  return (current / maxCapacity) * 100; // คิดเลขคำนวณร้อยละทันทีเมื่อตัวแปร stock เปลี่ยนแปลง!
});

📌 5. สถาปัตยกรรมจัดระเบียบองค์กร (Core / Shared / Features)

เพื่อให้โครงการไม่รกรุงรังเมื่อขยายตัว เรานิยมกรุ๊ปไฟล์แบ่งตามความรับผิดชอบ:

  • `core/` (แกนหลักบ้านชิ้นเดียว): เก็บของที่อุปโลกน์ขึ้นมารันเพียงครั้งเดียวทั้งแอป เช่น ตัวต่อ API, ตัวกรองความปลอดภัย Guard, Navbar สรุปแถมบนสุด
  • `shared/` (ห้องสมุดของส่วนกลาง): เป็นตู้เก็บชิ้นส่วนแบบ dumb (ไม่มีตรรกะเฝ้าสเตท) เช่น ปุ่มกดกลม ๆ ใส ๆ, กล่องยืนยันข้อความ Alert ที่หน้าไหนก็เรียกหยิบไปวางขยายได้
  • `features/` (หน้าเว็บย่อย): หน้าวิวหลัก ๆ แยกสัดส่วน เช่น แดชบอร์ดในบ้าน, ประวัติการลดสต๊อก ซึ่งภายในจะมี HTML และ CSS เฉพาะเจาะจงของมันเอง
